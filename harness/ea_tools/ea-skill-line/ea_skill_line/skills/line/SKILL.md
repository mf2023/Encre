## LINE Platform Guide

### When to Use
- Information about LINE official features, messaging, stickers, and LINE Pay
- Understand LINE's public API capabilities and official account management

### Key Resources
- Official website: https://line.me/
- Developer docs: https://developers.line.biz/

### Common Pitfalls
- LINE (Japan/Thailand/Taiwan) and WeChat (China) are separate platforms with different ecosystems
- LINE Pay availability varies by region; check which version applies
