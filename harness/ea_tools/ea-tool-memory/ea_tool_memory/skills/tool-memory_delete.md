# memory_delete

Permanently delete a memory file. Use this to remove obsolete or incorrect memories that should no longer influence future sessions. Do NOT use this for routine updates (use memory_update) or to clear the user profile (use memory_profile with appropriate updates). Tips: confirm the filename with memory_read or memory_search first. Pitfalls: deletion cannot be undone and there is no trash bin.
