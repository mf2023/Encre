# 输入样例

## 场景一：销售数据画像与质量检测

请对这份超市销售数据做完整的画像分析：

"这是我们有四家门店过去5个月的销售数据CSV，但感觉有些数据不太对。帮我看看数据质量怎么样，有没有异常值，哪些列缺失比较严重，然后给个清洗建议。"

（数据文件：`examples/sample_sales.csv`，52行，含日期/门店/品类/产品/单价/数量/销售额/会员类型，包含人工构造的缺失值和异常值）

---

## 场景二：自然语言转SQL

请将以下业务需求转换成标准SQL：

"帮我查一下：过去3个月，每个产品品类里销售额最高的那个产品是什么？另外，各门店金卡会员的客单价（即每笔交易的 revenue/qty）和普通会员比差多少？最后，按月统计每个品类的销售额环比增长率。"
