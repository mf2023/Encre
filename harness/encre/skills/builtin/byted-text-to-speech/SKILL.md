# Byted-Text-to-Speech Skill

Converts text to speech and saves as an audio file, based on [Volcengine Doubao Voice Synthesis](https://www.volcengine.com/docs/6561/1598757) (HTTP Chunked/SSE unidirectional streaming-V3).

## When to Use

Prioritize using this skill when the user has the following needs:

- Need to convert a piece of text to speech, audio reading
- Need to generate dubbing, narration, broadcast, audio book clips
- Need to convert code comments, documents, articles, etc. into audio for convenient listening
- Need to generate multilingual speech (Chinese, English, etc.)
- User mentions "text to speech", "TTS", "voice synthesis", "reading aloud", "dubbing", "read it out", "read to me"
- User does not explicitly say "voice synthesis", but the task essentially requires converting text content into playable audio

## Pre-Use Checks

First check whether the following credentials are configured:

- `MODEL_SPEECH_API_KEY`

If credentials are missing, open `references/setup-guide.md` to view the activation, application, and configuration methods, and provide activation guidance to the user

## Script Parameters

| Parameter | Short | Required | Description |
|------|------|------|------|
| `--text` | `-t` | Yes | Text content to synthesize |
| `--output` | `-o` | No | Output audio file path (auto-generated by default) |
| `--speaker` | `-s` | No | Speaker, default `zh_female_vv_uranus_bigtts`, [timbre list](https://www.volcengine.com/docs/6561/1257544) |
| `--format` | | No | Audio format: `mp3` (default), `pcm`, `ogg_opus` |
| `--sample-rate` | | No | Sample rate, e.g. 16000, 24000 (default 24000) |
| `--speech-rate` | | No | Speech rate [-50, 100], 100 = 2.0x speed, -50 = 0.5x speed, default 0 |
| `--pitch-rate` | | No | Pitch [-12, 12], default 0 |
| `--loudness-rate` | | No | Volume [-50, 100], 100 = 2.0x volume, -50 = 0.5x volume, default 0 |
| `--bit-rate` | | No | Bitrate, effective for mp3 and ogg_opus formats (e.g. 64000, 128000), default 64000 |
| `--filter-markdown` | | No | Filter markdown syntax (e.g. `**Hello**` reads as "Hello"), disabled by default |
| `--enable-latex` | | No | Enable LaTeX formula reading (uses latex\_parser v2, automatically enables markdown filtering), disabled by default |

## Return Value Description

The script outputs JSON containing:

- `status`: `"success"` or `"error"`
- `local_path`: Local audio file path
- `format`: Audio format
- `error`: Error message on failure

Return `local_path` or an accessible audio URL to the user for playback or download.

## Error Handling

- If the error `PermissionError: MODEL_SPEECH_API_KEY ... needs to be configured in environment variables` occurs: Prompt the user to obtain and configure `MODEL_SPEECH_API_KEY` from [API Key Management](https://console.volcengine.com/speech/new/setting/apikeys), write it to the workspace environment variable file, then retry.
- If a 4xx/5xx or business error code is returned: Based on the error message, prompt the user to check the text content, speaker ID, and whether the account has activated the Doubao voice service.

## Troubleshooting

- Missing credentials: Open `references/setup-guide.md`
- Need to look up API parameters, fields, error codes: Open `references/docs-index.md`
- If the script returns a permission error, first check whether the service has been activated and whether the credentials are valid, and provide the user with clear operational guidance

## Examples

```bash
# Basic usage
python scripts/text_to_speech.py -t "欢迎使用火山引擎语音合成服务。 (Welcome to Volcengine voice synthesis service.)"

# Specify speaker and output format
python scripts/text_to_speech.py -t "这是一段测试语音。 (This is a test voice.)" -s zh_female_vv_uranus_bigtts -o output.mp3 --format mp3

# Specify speech rate and sample rate
python scripts/text_to_speech.py -t "语速和音调可调。 (Speech rate and pitch are adjustable.)" --speech-rate 10 --sample-rate 16000
```
