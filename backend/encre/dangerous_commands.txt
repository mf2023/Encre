# ==============================================================================
# Encre Dangerous Command Patterns — Blacklist for terminal operations
#
# Format: one regex pattern per line.
# Section headers: [linux], [windows], [macos]
# Lines starting with '#' are comments and ignored.
# Empty lines are ignored.
#
# When permission_mode="blacklist", each subcommand produced by the shell
# splitter is tested independently. Any subcommand matching a pattern below
# triggers a permission prompt.
# ==============================================================================
