# Encre — 项目任务分解计划 (Task Breakdown Plan)

> 生成时间: 2025-07-17
> 分析范围: Python 后端框架 · Rust 原生核心 · Electron 桌面应用
> 版本: v0.2.0-dev (当前)

---

## 项目全景

**项目名称:** Encre
**项目定位:** 面向开发者的 AI Agent 框架 + 桌面 IDE
**技术栈:**
| 层 | 技术 | 代码量 |
|---|---|---|
| 后端框架 | Python 3.11+ (asyncio, Pydantic) | ~12K LOC |
| 原生核心 | Rust (Cargo workspace) | ~3K LOC |
| 桌面应用 | TypeScript (Electron + Monaco Editor) | ~8K LOC |

**核心架构:** 三层管道模型 `Agent → Adapter → Router → Backend`

---

## Phase 1: 后端核心框架完善 (高优先级)

> 目标: 建立稳定的 Agent 运行时核心，确保生命周期管理和消息处理正确。

### 任务 1.1 — Agent 类层次重构
- **描述:** 抽象 `BaseAgent` 基类，定义 `AgentSpec` 规范接口。当前 `Agent` 类耦合过多职责，需拆分为 `Agent → AgentContext → AgentSession` 三级。
- **验收标准:**
  - `BaseAgent` 定义 `run()`, `step()`, `handle_tool_call()`, `on_complete()` 抽象方法。
  - `AgentSession` 管理对话上下文、消息历史、token 计数。
  - 单元测试覆盖完整生命周期。
- **工作量:** 3-4 人天
- **依赖:** 无

### 任务 1.2 — 消息总线与事件系统
- **描述:** 实现 `EventBus` 发布-订阅模式，支持 `agent.started`, `tool.called`, `message.received`, `error.raised` 等事件。
- **验收标准:**
  - `EventBus.subscribe(event_type, handler)` / `.emit(event_type, payload)`。
  - 异步事件处理无阻塞。
  - 事件可序列化为 JSON。
- **工作量:** 2 人天
- **依赖:** 任务 1.1

### 任务 1.3 — Config 系统统一
- **描述:** 将分散的 `config.py` 合并为统一的 `ConfigManager`，支持 YAML/JSON/env 多层覆盖。
- **验收标准:**
  - 配置文件搜索顺序: 环境变量 > `~/.encre/config.yml` > 项目 `.encre.yml`。
  - Pydantic 校验，运行时热加载。
  - 向下兼容。
- **工作量:** 2 人天
- **依赖:** 无

### 任务 1.4 — 日志与追踪系统
- **描述:** 基于 `structlog` 构建结构化日志，集成 OpenTelemetry 追踪。
- **验收标准:** 每个 Agent 调用生成唯一 `trace_id`, JSON 格式输出，支持调试模式。
- **工作量:** 1-2 人天
- **依赖:** 任务 1.2

### 任务 1.5 — 错误处理与重试机制
- **描述:** 定义 `EncreException` 异常层次，实现指数退避重试。
- **验收标准:** 区分永久/临时错误，可配置重试策略，所有外部 API 调用包裹重试。
- **工作量:** 1-2 人天
- **依赖:** 无

## Phase 2: AI 后端集成与路由层 (高优先级)

> 目标: 实现多模型后端的统一调用接口和智能路由。

### 任务 2.1 — Backend 基类与工厂
- **描述:** 抽象 `BaseBackend` 接口 (`chat`, `stream_chat`, `embed`, `count_tokens`), 实现 `BackendFactory`。
- **工作量:** 2 人天
- **依赖:** 任务 1.3, 1.5

### 任务 2.2 — OpenAI 兼容后端
- **描述:** 对接 OpenAI API（含 Azure OpenAI、OpenRouter），支持流式/非流式、图片输入。
- **工作量:** 2 人天
- **依赖:** 任务 2.1

### 任务 2.3 — Anthropic Claude 后端
- **描述:** 对接 Messages API，处理 tool_use、extended thinking。
- **工作量:** 2 人天
- **依赖:** 任务 2.1

### 任务 2.4 — 本地模型后端 (Ollama/vLLM)
- **描述:** 对接 Ollama 或 OpenAI 兼容本地推理端点。
- **工作量:** 1-2 人天
- **依赖:** 任务 2.1

### 任务 2.5 — 智能 Router
- **描述:** 根据任务类型/成本/延迟自动选择后端，支持 fallback 链。
- **工作量:** 3 人天
- **依赖:** 任务 2.2, 2.3, 2.4

### 任务 2.6 — Token 管理与预算控制
- **描述:** Token 计数 (tiktoken)、窗口管理、预算上限控制，超预算自动切换低成本模型。
- **工作量:** 2 人天
- **依赖:** 任务 2.1

## Phase 3: 工具系统与能力层 (高优先级)

> 目标: 构建可扩展的工具注册、执行、沙箱体系。

### 任务 3.1 — Tool 规范与注册中心
- **描述:** 定义 `BaseTool`, `ToolRegistry`（schema 自动生成、冲突检测、权限标注）。
- **工作量:** 2 人天
- **依赖:** 任务 1.1

### 任务 3.2 — 文件系统工具集重构
- **描述:** 重构 file_read/write/edit/glob/grep，统一路径安全校验（防路径遍历），文件大小上限检测。
- **工作量:** 3 人天
- **依赖:** 任务 3.1, Phase 8

### 任务 3.3 — Shell 工具集
- **描述:** 命令行执行工具，超时控制、工作目录管理、命令黑名单、后台运行模式。
- **工作量:** 2 人天
- **依赖:** 任务 3.1, Phase 8

### 任务 3.4 — Web 工具集
- **描述:** 网页抓取、搜索 (DuckDuckGo/SearXNG)、RSS 订阅，遵守 robots.txt 和 rate limit。
- **工作量:** 2 人天
- **依赖:** 任务 3.1

### 任务 3.5 — 代码工具集
- **描述:** 集成 tree-sitter AST 搜索，ruff/prettier 格式化，unified diff 生成。
- **工作量:** 2-3 人天
- **依赖:** 任务 3.1

### 任务 3.6 — 工具沙箱 (Sandbox)
- **描述:** 可选安全执行环境，子进程/容器隔离，限制 CPU/memory/网络/文件系统。
- **工作量:** 4 人天
- **依赖:** 任务 3.1

## Phase 4: 适配器与通道层 (中优先级)

> 目标: 支持多种交互通道（CLI, HTTP, WebSocket, MCP, Slack 等）。

### 任务 4.1 — Adapter 基类与工厂
- **描述:** 抽象 `BaseAdapter` 接口，定义 `send()`, `receive()`, `format_message()`。
- **工作量:** 1 人天
- **依赖:** 任务 1.1

### 任务 4.2 — CLI 适配器 (交互式)
- **描述:** 交互式 CLI 界面 (prompt_toolkit/textual)，支持斜杠命令、彩色输出、历史记录。
- **工作量:** 2-3 人天
- **依赖:** 任务 4.1

### 任务 4.3 — MCP Server 适配器
- **描述:** 实现 Model Context Protocol 服务器，对外暴露 tool 和 resource。
- **工作量:** 3 人天
- **依赖:** 任务 4.1

### 任务 4.4 — HTTP API 适配器
- **描述:** FastAPI REST API (`/api/chat`, `/api/tools`)，支持 SSE 流式，API Key 鉴权。
- **工作量:** 2 人天
- **依赖:** 任务 4.1

### 任务 4.5 — WebSocket 实时通道
- **描述:** 双向实时通信，支持 `message`, `tool_call`, `tool_result`, `status`, `error` 消息类型。
- **工作量:** 1-2 人天
- **依赖:** 任务 4.4

## Phase 6: 学习进化与记忆系统 (中优先级)

> 目标: 为 Agent 赋予长期记忆和持续学习能力。

### 任务 6.1 — 记忆存储层
- **描述:** `MemoryStorage` 接口，SQLite 实现（结构化记忆）+ ChromaDB/FAISS 实现（向量语义搜索）。
- **工作量:** 3 人天
- **依赖:** 无

### 任务 6.2 — 对话记忆管理
- **描述:** 短期记忆（会话窗口内）+ 长期记忆（自动摘要入向量库）+ 相关性检索。
- **工作量:** 2 人天
- **依赖:** 任务 6.1

### 任务 6.3 — 工具使用模式学习
- **描述:** 记录每次工具调用，分析高频工具/失败模式，提供优化建议。
- **工作量:** 2 人天
- **依赖:** 任务 6.1

### 任务 6.4 — Evolution 自改进框架
- **描述:** Evaluator（评分）+ Mutator（改进策略）+ Evolver（执行改进）闭环。
- **工作量:** 4 人天
- **依赖:** 任务 1.1, 2.1

- **依赖:** 任务 1.1

- **描述:** 预定义角色模板（协调者/编码者/审查者），任务自动分解分配。

- **依赖:** 任务 7.1

- **描述:** 代码 diff 合并、文档结构化合并、Agent 间相互审查。

- **依赖:** 任务 7.1, 3.2

## Phase 8: 安全加固与生产部署 (高优先级)

### 任务 8.1 — 输入验证与注入防护
- **描述:** 命令注入检测、Prompt 注入检测（关键字+启发式）、敏感信息脱敏。

### 任务 8.5 — 密钥管理

| 路径 | 阶段 | 说明 |

| CP1 | 1.1 → 1.2 → 2.1 → 2.5 | Agent 核心 → 路由 → 多模型 |
