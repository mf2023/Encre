# 法律文档索引（Legal Documentation Index）

本目录按「洲 / 国家或地区代码」组织，每个辖区包含六份本地化法律文档：

| 文件 | 内容 |
|---|---|
| `PRIVACY.md` | 隐私政策 |
| `TERMS.md` | 服务条款 |
| `USER_AGREEMENT.md` | 用户协议 |
| `MINORS_PRIVACY.md` | 未成年人数据保护 |
| `CONTENT_GUIDELINES.md` | 社区/内容准则 |
| `DATA_PROCESSING.md` | 数据处理说明 |

各文件以其所在司法辖区的适用语言撰写；标注「当地语言版本优先」的辖区，以当地语言版本为准。桌面端应用内的默认英文入口指向 **美国（us）** 版本，中文入口指向 **中国大陆（cn）** 版本（见 `desktop/main.ts`）。

> 所有文档仅供信息参考，不构成法律意见。
