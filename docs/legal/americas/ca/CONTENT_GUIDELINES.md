## 1. Purpose and architecture

Encre Agent is local-first: agents and prompts process on your device by default. These guidelines apply when you publish, share content, or use optional cloud surfaces.

| Layer | Processing | Guideline scope |
|---|---|---|
| Local agents | No server checks | Your responsibility |
| Shared/published agents | Moderated | Fully applicable |
| Cloud inference (PiscesLx) | Technical processing | Abuse prevention |
| Chat integrations | Platform rules apply | Follow platform policies |

## 2. Prohibited content

Prohibited via shared or cloud services:

- **Child sexual abuse material** — Criminal Code s. 163.1; we escalate to law enforcement and Cybertip.ca (Canadian Centre for Child Protection);
- **Hate propaganda** — Criminal Code ss. 318–320;
- **Non-consensual intimate images** — Criminal Code s. 162.1; rapid removal on request from depicted persons or their representatives;
- Threats, extortion, harassment (ss. 264.1, 346, 264), counselling offences;
- Fraud (s. 380), phishing, spam;
- Malware distribution, unauthorized computer use (s. 342), identity theft (ss. 402.2, 403);
- Copyright/trademark infringement (Copyright Act, Trademarks Act);
- Content otherwise unlawful under Canadian law.

## 3. AI-specific rules

3.1 AI-generated content must not be passed off as human-authored where that would deceive.

3.2 Synthetic media ("deepfakes") must be identifiable as synthetic; non-consensual sexualized depictions of real persons are strictly prohibited.

3.3 Users remain responsible for what they publish, including AI output.

## 4. Reporting and enforcement

4.1 Report violations to **dunimd@outlook.com** with context. CSAM reports trigger immediate action and escalation.

4.2 Enforcement ladder: warning → feature limits → content removal → account suspension/termination. Appeals accepted.

4.3 Where criminal conduct is suspected we may report to police; we preserve evidence per lawful requirements.
