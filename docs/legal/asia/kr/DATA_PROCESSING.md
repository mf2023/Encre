# 데이터 처리 규칙（대한민국）

**최종 업데이트：2026년 8월 22일**
**상위 문서：** [개인정보 보호 방침](PRIVACY.md)

## 1. 로컬퍼스트 선언

**Encre는 로컬퍼스트 설계입니다：**

- 대화 내용·프롬프트·AI 출력·세션 이력·설정·스킬·메모리·인덱스는 **모두 사용자 단말에 저장**됩니다.
- **순수 로컬 모드**(클라우드 AI 백엔드 미설정)에서는 **Dunimd 서버가 일절 개입하지 않습니다**.
- 소스 코드는 Apache 2.0으로 공개되어 본 선언을 직접 감사할 수 있습니다.

따라서 일반적인 이용에서 당사는 사용자 개인정보의 처리자가 아닙니다.

## 2. 데이터 흐름

| 데이터 | 기본 위치 | 단말 밖으로 나가는 경우 |
|---|---|---|
| 프롬프트／대화／AI 출력 | 단말 | 클라우드 백엔드 설정 시만 (직접 전송) |
| 설정／스킬／메모리／인덱스 | 단말 | 없음 |
| API 키 | 단말 암호화(AES-256-GCM) | 키 발급처에만 |
| 텔레메트리／크래시 로그 | **기본 꺼짐** | 활성화 후 당사로 |
| 계정 정보 | Dunimd Cloud 리전 | 가입·결제 시 |
| 위탁 추론 메타데이터 | 당사 인프라 | PiscesLx 이용 시. 내용은 기본 미보관 |

## 3. 서비스별

| 서비스 | 처리 위치 | 당사 서버 경유 |
|---|---|---|
| Encre | 단말 | 로컬：아니오；클라우드：메타데이터만 |
| PiscesLx | 당사 클라우드 또는 고객 환경 | 이용 시；내용 기본 미보관 |
| Enterprise | 고객 환경 | 아니오 |
| StadionOS | 고객 하드웨어 | 텔레메트리 기본 꺼짐 |
| Cloud | 당사 클라우드 | 선택 워크로드만 |
| Studio | 로컬 | 익명 라이선스 ping만 |

## 4. 텔레메트리

데스크톱·개발자 도구 **기본 수집 없음**. 활성화 전 항목 고지 및 동의, 언제든 중단 가능. 키 입력·화면·클립보드·브라우징 기록은 수집하지 않음.

## 5. 국외 이전

순수 로컬 모드는 국외 이전 없음. 해외 모델 설정 시 해당 데이터는 **단말에서 직접** 그 제공자로 전송(당사 미경유). 당사 자체 이전 시 PIPA 제28조의9에 따른 고지·동의·조치를 취합니다.

## 6. 안전성·보관

TLS 1.2+／AES-256-GCM／최소권한·감사. 보관：로컬=사용자 관리；추론 내용=기본 미보관；메타데이터=12개월 후 익명화；지원 기록=24개월；청구 기록=법정 기간.

## 7. 변경

로컬퍼스트를 중단하는 경우 30일 전 고지하고 다시 동의를 받습니다.
