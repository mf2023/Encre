# Data Processing Rules (Singapore)
**Last updated: 22 Aug 2026** · Parent: [Privacy](PRIVACY.md)

**Local-first:** Encre stores all content on your device; pure local mode = zero data through Dunimd servers; Apache-2.0 auditable. Flow: prompts/chats/output → device (cloud backends receive directly only if you configure); settings/skills/memory/indexes → device never leaves; API keys encrypted AES-256-GCM; telemetry/crash logs off by default; account info → chosen region; hosted-inference metadata only (no content retained by default). Per service: Encre device; PiscesLx our cloud/customer env; Enterprise customer env; StadionOS customer hardware (telemetry off); Cloud chosen workloads; Studio local anonymous ping; Support submitted materials only. Telemetry: none by default, explicit opt-in, no keystrokes/screen/clipboard/history. Transfers: pure local none; offshore models device-direct by your choice; ours comply with PDPA s.26 + PDPC guidance. Security TLS1.2+/AES-256-GCM/least privilege. Retention: inference content none; metadata ≤12m anonymised; support ≤24m; billing per tax law. 30-day notice if local-first defaults change.
