## 1. 基本原則

1.1 我們對兒童資料的處理以最小必要為限。

1.2 我們不會向兒童投放廣告，也不會將兒童資料用於營銷目的。

## 2. 年齡門檻與家長同意

2.1 註冊雲端服務須年滿 **13 歲**。本著審慎原則，**16 歲以下**未成年人需要家長或監護人的同意（參考澳門《民法典》關於未成年人行為能力的規定）。

2.2 本地基本功能無需帳戶；同樣適用上述年齡限制。

2.3 如我們得悉存在未經同意的未成年人資料，會刪除該等資料。

## 3. 家長的權利

3.1 家長可代未成年人行使查閱及更正權，並在法律許可範圍內要求刪除。

3.2 請求請發送至 dunimd@outlook.com——我們一般會在 30 天內回覆。

## 4. Local-first 架構作為保障

4.1 Encre Agent 預設在本地儲存所有數據：提示詞、回應與歷史記錄保留在裝置上，不會被傳輸。

4.2 遙測預設關閉。未經明確同意，我們絕不會將未成年人內容用於模型訓練。

## 5. 學校及非商業用途

5.1 學校可將 Encre Agent 用於教學用途；建議在班級層面進行數據最小化設定。

5.2 學校應遵守教育當局指引及學校自身的私隱要求。

## 6. 聯絡與舉報

問題、家長請求或違規舉報：dunimd@outlook.com · dunimd.com

監管機構：個人資料保護辦公室（DSPP），dspp.gov.mo

涉及兒童性剝削內容的舉報會立即轉介司法機關處理（見[內容準則](CONTENT_GUIDELINES.md)）。
