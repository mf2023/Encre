## 1. 宗旨與架構

1.1 Encre Agent 是開放平台：Agent 及提示詞預設僅在你的裝置上本地處理。

1.2 只有當你發佈、共享內容或連接可選服務時，本準則才適用。

| 層級 | 處理 | 準則適用性 |
|---|---|---|
| 本地 Agent | 無伺服器端審核 | 你自己的責任 |
| 共享／已發佈的 Agent | 審核 | 完全適用 |
| 雲端推理 (PiscesLx) | 技術處理 | 防濫用 |
| 聊天平台整合 | 平台規則並行適用 | 遵守平台政策 |

## 2. 禁止內容

禁止透過共享或雲端服務傳播：

- **兒童色情內容**——零容忍，立即舉報並轉介司法機關；
- 威脅、恐嚇、勒索（《刑法典》相關規定）；
- 誹謗及侮辱他人；
- 妨害電腦系統正常運作的內容（未經授權進入、干擾數據）；
- 詐騙、釣魚及垃圾訊息；
- 侵犯著作權及相關權利的內容；
- 其他違反澳門強制性法律的內容。

## 3. AI 特定規則

3.1 **透明度**：AI 生成的內容不得偽裝成人類創作；合成媒體（deepfake）必須標識為虛構內容。

3.2 **禁止濫用**：不允許利用 AI 進行針對性的欺詐或損害他人名譽。

3.3 **輸出責任**：發佈 AI 輸出的用戶對其內容負責。

## 4. 舉報與執法

4.1 違規舉報：**dunimd@outlook.com**（請附相關內容與背景）。涉及兒童性剝削內容的舉報會立即採取行動。

4.2 執法階梯：警告 → 功能限制 → 內容移除 → 帳號封禁。每項措施均可提出申訴。

4.3 如涉嫌刑事罪行，我們保留向澳門司法機關轉介的權利。

## 5. 變更

本準則的變更會至少提前 30 天公佈。
