## 1. 適用範圍與合同成立

1.1 本條款規範 Dunimd（下稱「Dunimd」或「我們」）與澳門私人及商業客戶之間的服務使用。

1.2 通過註冊帳戶、下載桌面應用或實際使用某項服務，即表示你接受本條款，合同由此成立。

## 2. 我們的服務

| 服務 | 說明 | 可用性 |
|---|---|---|
| **Encre Agent 桌面版** | local-first AI Agent 桌面應用 | Windows, macOS, Linux |
| **Encre Agent 框架** | Python 框架與 Rust 原生核心 | 開源，github.com/mf2023/Encre |
| **聊天平台整合** | 18 個平台的連接器 | 視平台可用性 |
| **PiscesLx** | 託管 LLM 推理（可選） | 訂閱制 |
| **StadionOS** | 操作系統項目 | 獨立許可 |
| **Dunimd Enterprise / Cloud / Studio / Support** | 商業產品與服務 | 按協議 |

2.2 基本功能設計為在本地運行；雲端始終為可選項。

## 3. 帳戶與安全

3.1 雲端服務需要帳戶。請妥善保管登入憑證，並對帳戶下的活動負責。

3.2 發現未經授權的使用請立即通知：dunimd@outlook.com。

## 4. 軟件許可

4.1 開源組件按照 github.com/mf2023/Encre 各存儲庫聲明的許可證提供。

4.2 專有組件（例如部分企業模組）在無明確書面約定時，授予非獨佔、不可再許可、不可轉讓的使用權。

## 5. 付費服務、價格與退訂

5.1 價格以澳門元（MOP）列示；所有價格另加適用稅項。

5.2 訂閱期限與付款條件於訂購時顯示。

5.3 作為自願性安排，我們在未大量使用的情況下提供自購買起 **14 天內**的退款。此安排不影響法定權利。

## 6. 責任

6.1 我們僅對故意或過失造成的損害承擔責任；責任範圍限於可預見的典型直接損害。

6.2 針對人身傷害的強制性法定責任不受影響。

## 7. 違約與終止

7.1 違反本條款、[用戶協議](USER_AGREEMENT.md)或[內容準則](CONTENT_GUIDELINES.md)可導致功能限制直至終止合同。

7.2 定期訂閱可於期末隨時終止；因重大理由的即時終止不受影響。

## 8. 準據法與管轄

8.1 本條款受澳門特別行政區法律管轄。

8.2 澳門特別行政區法院擁有管轄權；法律賦予消費者的強制性保護不受影響。
