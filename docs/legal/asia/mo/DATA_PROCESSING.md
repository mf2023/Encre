## 1. Local-first 聲明

1.1 Encre Agent 以本地優先方式設計：Agent 定義、提示詞、回應、對話歷史及整合均保存在你的裝置上。

1.2 遙測預設關閉。提示詞與回應不會被預設儲存。

1.3 只有當你主動啟用雲端服務時，才會發生超出你裝置的處理。

## 2. 數據流

| 數據 | 位置 | 存留期 |
|---|---|---|
| Agent 配置、工作流程 | 僅限裝置 | 直至刪除 |
| 對話歷史 | 僅限裝置 | 由用戶控制 |
| API 金鑰（第三方提供商） | 裝置上的加密儲存 | 直至刪除 |
| 雲端推理請求 | 處理後刪除 | 會話期間 |
| 服務元數據（時間戳、錯誤代碼） | 伺服器端 | 最長 30 天 |
| 遙測（可選開啟） | 伺服器端 | 最長 90 天 |
| 帳戶數據（僅限雲端服務） | 伺服器端 | 直至帳戶刪除 |

## 3. 按服務劃分的處理

3.1 **PiscesLx（託管 LLM）：** 請求經 TLS 加密傳輸並在記憶體內處理；元數據最多保留 30 天後自動刪除。

3.2 **Encre Agent 桌面版／框架：** 無伺服器端處理；所有數據保留在本地。

3.3 **聊天平台整合：** 平台自身的私隱政策適用於平台側數據。

## 4. 遙測

4.1 遙測嚴格採用選擇加入（opt-in）機制：在你明確同意之前，不會發送任何診斷數據。

4.2 可隨時在設定中停用遙測；現有的遙測數據會被刪除。

## 5. 安全與事故通報

5.1 技術措施：傳輸加密（TLS 1.2+）、靜態加密（AES-256-GCM）、最小權限訪問。

5.2 一旦發生可能影響當事人權益的資料安全事故，我們會盡快通知個人資料保護辦公室（DSPP）及受影響的當事人。

## 6. 跨境傳輸

6.1 在接收地未能提供充分保護的情況下，如需跨境傳輸，我們會按照第 8/2005 號法律的相關要求取得 DSPP 許可或你的明確同意，並以合約手段確保同等保障。

## 7. 變更與聯絡

7.1 本說明的變更會至少提前 30 天公佈。

7.2 聯絡方式：dunimd@outlook.com · dunimd.com · 監管機構：個人資料保護辦公室（DSPP），dspp.gov.mo
