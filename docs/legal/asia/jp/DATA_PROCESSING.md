# データ処理規則（日本）

**最終更新：2026 年 8 月 22 日**
**適用範囲：** Dunimd 全サービスのデータフロー・保存場所・処理方法

> 上位文書：[個人情報保護方針](PRIVACY.md)

## 1. ローカルファースト宣言

**Encre は「ローカルファースト」設計です：**

- 対話内容・プロンプト・AI 出力・セッション履歴・設定・スキル・記憶・インデックスは**すべてお客様の端末内**に保存されます。
- **純ローカルモード**（クラウド AI バックエンド未設定）では、**Dunimd のサーバーは一切関与しません**。
- ソースコードは Apache 2.0 で公開されており、本宣言はご自身で監査可能です。

したがって通常のご利用において、当社はお客様の個人データの取扱事業者ではありません。

## 2. データフロー一覧

| データ | 既定の場所 | 端末外に出る条件 |
|---|---|---|
| プロンプト／対話内容／AI 出力 | 端末内 | クラウド後端設定時のみ（当該後端へ直送） |
| 設定／スキル／記憶／索引 | 端末内 | なし |
| API キー | 端末内暗号化（AES-256-GCM） | キー発行者へのみ |
| テレメトリ／クラッシュログ | **既定オフ** | 有効化後に当社へ |
| アカウント情報 | Dunimd Cloud 選択リージョン | 登録・課金時 |
| 託管推論メタデータ（タイムスタンプ・モデルID・Token 数） | 当社インフラ | PiscesLx 利用時。内容は既定非保存 |

## 3. サービス別

| サービス | 処理場所 | 当社サーバー経由 |
|---|---|---|
| Encre（18 プラットフォーム連携含む） | 端末内 | ローカル：否；託管雲：メタデータのみ |
| PiscesLx | 当社クラウド又は顧客環境 | 利用時のみ；内容既定非保存 |
| Enterprise | 顧客環境 | 否 |
| StadionOS | 顧客ハード | テレメトリ既定オフ |
| Cloud | 当社クラウド | 選択されたワークロードのみ |
| Studio | ローカル | ライセンス ping のみ匿名 |

## 4. テレメトリ

デスクトップアプリ・開発者ツールは**既定でテレメトリ収集なし**。有効化前に項目を明示し同意を取得、いつでも停止可能。キーストローク・画面内容・クリップボード・閲覧履歴は収集しません。

## 5. 越境移転

純ローカルモードでは越境移転なし。お客様が海外モデル（OpenAI 等）を設定した場合、当該データは端末から**直接**当該海外事業者へ送信され、当社は経由しません（APPI 第28条の当事者はお客様）。当社自らが外国第三者へ提供する場合は所要の措置（同意・制度情報提供等）を講じます。

## 6. 安全管理措置・保存期間

TLS 1.2+／AES-256-GCM／最小権限・監査。保存期間：ローカルデータ＝利用者が管理；推論内容＝既定非保存；メタデータ＝12ヶ月以内匿名化；サポート記録＝24ヶ月；請求記録＝法定期間。

## 7. 変更

「ローカルファースト」をやめる場合は30日前に告知し、改めて同意を取得します。
