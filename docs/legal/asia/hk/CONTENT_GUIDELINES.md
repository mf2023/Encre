## 1. 宗旨與架構

1.1 Encre Agent 是開放平台：Agent 及提示詞預設僅在你的裝置上本地處理。

1.2 只有當你發佈、共享內容或連接可選服務時，本準則才適用。

| 層級 | 處理 | 準則適用性 |
|---|---|---|
| 本地 Agent | 無伺服器端審核 | 你自己的責任 |
| 共享／已發佈的 Agent | 審核 | 完全適用 |
| 雲端推理 (PiscesLx) | 技術處理 | 防濫用 |
| 聊天平台整合 | 平台規則並行適用 | 遵守平台政策 |

## 2. 禁止內容

禁止透過共享或雲端服務傳播：

- **兒童色情**：《防止兒童色情物品條例》（第 579 章）——立即舉報並轉介警方；
- **起底／doxxing**：《個人資料（私隱）條例》第 64 條（2021 年修訂）禁止未經同意披露個人資料造成滋擾、煩擾等傷害；PCPD 可發出停止披露通知；
- **淫褻及不雅物品**：《淫褻及不雅物品管制條例》（第 390 章）；
- 刑事恐嚇、詐騙（第 210 章）、威脅或煽動暴力；
- 誹謗性陳述；
- 侵犯版權（《版權條例》第 528 章）或商標權；
- 未經授權存取電腦（《刑事罪行條例》第 161 條）、刑事損壞（第 200 章）；
- 虛假商品說明（《商品說明條例》第 362 章）；
- 其他違反香港強制性法律的內容。

## 3. AI 特定規則

3.1 **透明度**：按照 PCPD《人工智能 (AI): 個人資料保障模範框架》（2024 年 6 月），AI 生成的內容不得偽裝成人類創作。合成媒體（deepfake）必須識別為虛構內容。

3.2 **禁止濫用**：不允許利用 AI 進行針對性的欺詐、詐騙或損害他人名譽。

3.3 **輸出責任**：發佈 AI 輸出的用戶對其內容負責。

## 4. 舉報與執法

4.1 違規舉報：**dunimd@outlook.com**（請附相關內容與背景）。涉及第 579 章內容的舉報會立即採取行動並轉介香港警務處。

4.2 執法階梯：警告 → 功能限制 → 內容移除 → 帳號封禁。每項措施均可提出申訴。

4.3 如涉嫌刑事罪行，我們保留向執法機關轉介的權利，並配合 PCPD 就第 64 條罪行進行的刑事調查。

## 5. 變更

本準則的變更會至少提前 30 天公佈。
