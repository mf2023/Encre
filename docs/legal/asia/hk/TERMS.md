## 1. 適用範圍與合約訂立

1.1 本條款規範 Dunimd 與香港用戶之間的服務使用關係。

1.2 註冊帳戶、下載桌面應用或實際使用即接受本條款，合約隨之成立。

## 2. 我們的服務

| 服務 | 說明 |
|---|---|
| Encre Agent 桌面版 | 本地優先 AI Agent 桌面應用 |
| Encre Agent 框架 | Python 框架與 Rust 原生核心（開源） |
| 聊天平台集成 | 18 個平台的連接器 |
| PiscesLx | 託管 LLM 推理（可選） |
| StadionOS | 操作系統項目（獨立授權） |
| Dunimd Enterprise / Cloud / Studio / Support | 商業產品與服務 |

2.2 基礎功能在本地運行；雲端功能為可選項（見[數據處理說明](DATA_PROCESSING.md)）。

## 3. 帳戶與安全

3.1 雲端功能需要帳戶；請妥善保管登入憑證。發現未經授權的使用請立即通知 dunimd@outlook.com。

## 4. 軟件授權

4.1 開源組件按其儲存庫 github.com/mf2023/Encre 所載許可證提供；專有組件授予非獨家、不可再授權的使用權（另有書面約定除外）。

## 5. 收費服務、價格與退款

5.1 價格以港幣標示並另加適用稅項；訂閱條款於購買時列明。

5.2 **自願退款安排**：香港法例沒有強制的網購冷靜期。作為自願政策，我們在服務未被大量使用的情況下，提供購買後 14 天內的退款；法定權利不受影響。

## 6. 法律責任

6.1 在《管制免責條款條例》（第 71 章）的「合理程度」標准允許的範圍內限制責任：

- 我們不排除或限制因疏忽引致死亡或人身傷害的法律責任；
- 對消費者的法定權利（《貨品銷售條例》、《服務供應（隱含條款）條例》）不作排除；
- 其餘責任以您在過去 12 個月已支付的費用為限。

## 7. 違規與終止

7.1 違反本條款、[用戶協議](USER_AGREEMENT.md)或[社區準則](CONTENT_GUIDELINES.md)可導致功能受限直至終止。

7.2 定期訂閱可於期末取消；因重大理由即時終止的權利不受影響。

## 8. 管轄法律與司法管轄區

8.1 本條款受中華人民共和國香港特別行政區法律管轄。

8.2 香港特別行政區法院享有非排他的司法管轄權。
