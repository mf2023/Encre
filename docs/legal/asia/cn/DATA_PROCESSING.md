## 1. 核心架构声明：本地优先

**Dunimd 的旗舰服务 Encre Agent 采用"本地优先"（Local-first）架构：**

- 对话内容、提示词、AI 输出、会话历史、配置文件、技能、记忆与索引，**全部保存在您自己的设备上**（默认路径为用户数据目录）；
- 在**纯本地模式**下（不配置任何云端 AI 后端），**没有任何数据经过 Dunimd 的服务器**——我们既看不到也无法接触您的内容；
- 源代码以 Apache 2.0 开源，您可以自行审计上述声明的真实性。

这一架构意味着：对绝大多数使用场景而言，**Dunimd 不是您个人信息的接收方**；您是唯一的数据处理者。

## 2. 数据流向总表

| 数据类别 | 默认位置 | 何时会离开您的设备 |
|---|---|---|
| 提示词 / 对话内容 | 本地设备 | 仅当您主动配置云端 AI 后端时，直达该后端 |
| AI 输出 | 本地设备 | 同上（作为响应返回） |
| 配置 / 技能 / 记忆 / 索引 | 本地设备 | 从不 |
| API 密钥 | 本地加密存储（AES-256-GCM） | 仅发送至密钥所属服务商 |
| 遥测 / 崩溃日志 | 默认**关闭** | 您显式开启后才发送至 Dunimd |
| 账户信息（如使用托管功能） | Dunimd Cloud 所选区域 | 注册/付费时提供 |
| 托管推理元数据（时间戳、模型 ID、Token 数） | Dunimd 基础设施 | 使用 PiscesLx 托管推理时 |
| 托管推理内容（提示词与响应） | 不保留 | 默认不落盘 |

## 3. 各服务数据流说明

| 服务 | 处理位置 | 是否经过 Dunimd 服务器 |
|---|---|---|
| **Encre Agent**（桌面应用 / Python 框架 / Rust 核心 / 18 个聊天平台适配器） | 您的设备 | 纯本地模式：否；启用托管云：仅元数据 |
| **PiscesLx**（基础模型 / 微调 / 推理 API） | Dunimd 托管云或客户环境 | 是（使用时）；内容默认不保留 |
| **Dunimd Enterprise** | 客户自有环境（本地 / 私有云） | 否（数据留在客户处） |
| **StadionOS** | 客户硬件 | 遥测默认关闭；更新校验含设备匿名标识 |
| **Dunimd Cloud** | Dunimd 托管云（开通时选区） | 是（承载您选择的工作负载） |
| **Dunimd Studio**（IDE 插件 / CLI / SDK） | 本地 | 否；许可证校验 ping 匿名 |
| **Dunimd Support** | Dunimd 管理 | 仅限您主动提交的材料 |

## 4. 遥测政策

- 桌面应用与开发者工具**默认不采集任何遥测数据**；
- 开启遥测前，我们会明示收集项并取得同意；可随时一键关闭；
- 我们不采集击键、屏幕内容、剪贴板或浏览历史。

## 5. 跨境情形（重要）

依据《个人信息出境标准合同办法》《数据出境安全评估办法》《促进和规范数据跨境流动规定》：

1. **纯本地模式无出境**——不配置境外后端即不存在数据出境。
2. 若您在境内配置**境外 AI 后端**（OpenAI、Anthropic 等），内容由**您的设备直接发送至该境外服务商**，未经我们中转。此情形下的出境方是**您本人**，相应评估、标准合同签署等合规义务由您自行履行。
3. PiscesLx 中国大陆实例默认数据不出境。
4. 我们不会主动将您的任何数据传输至境外。

## 6. 安全措施

- 传输加密 TLS 1.2+；本地敏感数据 AES-256-GCM 加密；
- 最小权限访问控制 + 审计；
- 生产 / 开发隔离，MFA 准入；
- 安全事件响应流程见隐私政策 §9.2。

## 7. 保留期限

| 数据 | 期限 |
|---|---|
| 本地数据 | 由您全权管理，删除软件即删除数据 |
| 托管推理内容 | 默认不保留 |
| 推理元数据 | ≤12 个月后匿名化 |
| 支持工单材料 | ≤24 个月 |
| 计费记录 | 按税法要求（通常 7 年） |

## 8. 变更控制

若未来某服务的默认架构不再是"本地优先"，我们将提前 30 日公告，并重新履行告知同意义务。
