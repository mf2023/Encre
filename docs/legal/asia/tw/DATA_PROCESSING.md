# 資料處理規則（臺灣）

**最後更新：2026 年 8 月 22 日**
**適用範圍：** Dunimd 全部服務之資料流向、儲存位置與處理方式
**上位文件：** [個人資料保護聲明](PRIVACY.md)

---

## 1. 核心架構聲明：本地優先

**Dunimd 旗艦服務 Encre 採「本地優先」（Local-first）架構：**

- 對話內容、提示詞、AI 輸出、工作階段紀錄、設定、技能、記憶與索引，**全部儲存在您自己的裝置上**；
- **純本地模式**下（未設定任何雲端 AI 後端），**沒有任何資料經過 Dunimd 的伺服器**——我們接觸不到您的內容；
- 原始碼以 Apache 2.0 開源，您可自行稽核本聲明。

因此，在絕大多數使用情境中，**Dunimd 不是您個人資料的蒐集者**；您是唯一之資料處理者。

## 2. 資料流向總表

| 資料類別 | 預設位置 | 何時離開您的裝置 |
|---|---|---|
| 提示詞／對話內容 | 本地裝置 | 僅當您主動設定雲端 AI 後端時，直達該後端 |
| AI 輸出 | 本地裝置 | 同上 |
| 設定／技能／記憶／索引 | 本地裝置 | 從不 |
| API 金鑰 | 本地加密（AES-256-GCM） | 僅傳送至金鑰所屬服務商 |
| 遙測／當機日誌 | 預設**關閉** | 您顯式開啟後才傳送至 Dunimd |
| 帳戶資訊（如用託管功能） | Dunimd Cloud 所選區域 | 註冊／付費時提供 |
| 託管推論內容（提示與回應） | 不保留 | 預設不落盤；僅元數據（時間戳、模型 ID、Token 數）留存於 Dunimd |

## 3. 各服務資料流

| 服務 | 處理位置 | 是否經過 Dunimd 伺服器 |
|---|---|---|
| **Encre**（桌面應用／Python 框架／Rust 核心／18 平台介接） | 您的裝置 | 純本地模式：否；啟用託管託管雲：僅元數據 |
| **PiscesLx** | Dunimd 託管雲或客戶環境 | 使用時是；內容預設不保留 |
| **Dunimd Enterprise** | 客戶自有環境 | 否 |
| **StadionOS** | 客戶硬體 | 遙測預設關閉 |
| **Dunimd Cloud** | Dunimd 託管雲 | 是（承載您選擇的工作負載） |
| **Dunimd Studio** | 本地 | 否；授權校驗 ping 匿名 |
| **Dunimd Support** | Dunimd 管理 | 僅限您主動提交之材料 |

## 4. 遙測政策

桌面應用與開發者工具**預設不蒐集任何遙測**；開啟前將明示蒐集項目並取得同意，可隨時關閉。不蒐集按鍵、螢幕內容、剪貼簿或瀏覽紀錄。

## 5. 國際傳輸

1. 純本地模式無國際傳輸。
2. 您設定境外 AI 後端（如 OpenAI、Anthropic）時，內容由**您的裝置直接**傳送至該境外服務商，未經我們轉手；該傳輸由您決定並受其政策約束。
3. 我們不會主動將您的個人資料傳輸至我國領域外（《個人資料保護法》第 21 條參照）。

## 6. 安全措施

TLS 1.2+ 傳輸加密；本地敏感資料 AES-256-GCM；最小權限＋稽核；定期安全評估；漏洞通報見 [`docs/SECURITY.md`](../../../SECURITY.md)。

## 7. 保留期限

| 資料 | 期限 |
|---|---|
| 本地資料 | 由您全權管理；移除軟體即移除 |
| 託管推論內容 | 預設不保留 |
| 推論元數據 | ≤12 個月後匿名化 |
| 支援工單材料 | ≤24 個月 |
| 計費紀錄 | 依稅法要求 |

## 8. 變更控制

任一服務若不再採「本地優先」預設，我們將提前 30 日公告並重新履行告知義務。
