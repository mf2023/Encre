## 2. Description of Service

Dunimd is a general-purpose AI agent desktop application that enables users to interact with various AI models through a unified interface. The Software provides, among other features:

- Multi-model chat and task execution
- File and code analysis
- Agent-based workflow automation
- Integration with third-party AI backends (OpenAI, Anthropic, Ollama, and more)
- Local processing capabilities with self-hosted models
- Web search and browsing capabilities
- File processing (PDF, DOCX, Excel, images)
- Screen capture and automation
- Multi-platform messaging integration (Discord, Slack, Telegram, DingTalk)

The Software is provided as a desktop application that operates primarily on your local machine. Certain features may require connection to AI model backends (local, self-hosted, or third-party).
